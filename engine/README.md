# Verified network engine payload

The files in this directory were extracted from the immutable Flowseal
`zapret-discord-youtube` 1.10.3 release archive. The archive SHA-256 published by
GitHub is recorded in `engine-manifest.json`; the service verifies critical
files again before every engine start.

The payload contains upstream zapret/winws and WinDivert components. It remains
under the respective upstream licenses in `../licenses`. Rafferty does not
claim authorship of these files.
